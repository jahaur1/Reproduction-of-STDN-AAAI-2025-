# 三种交通流扰动与统一比较协议

输入为`[sample,time,node,feature]`，只修改第0个流量特征。训练、验证、测试都加入扰动；未来预测真实目标始终保持干净。默认扰动种子2024，与模型训练种子分开记录。

| 类型 | 构造方法 |
| --- | --- |
| 节点缺失`node` | 固定随机排列选前floor(N×r)个节点，所有输入样本和时间步的这些节点流量置0；三个划分和三个模型节点集合一致 |
| 连续缺失`node_gap` | 每个12步历史窗口划分为4个不重叠3步块；每节点独立抽取floor(S×4×r)块置0；相邻块可以同时选中，连续缺失可能超过3步 |
| 高斯噪声`noise` | 在S×12×N个位置中不放回抽取floor(S×12×N×r)个点，叠加N(10,500²)，之后执行max(x,0) |

比例取10%、20%、30%。与参考代码一致，每个划分重新使用相同随机种子；节点集合始终相同，但噪声和连续缺失位置随划分大小变化。连续缺失按样本窗口定义，同一原始时间点出现在不同重叠窗口中时可以具有不同扰动状态。噪声比例之间不强制选中位置互相包含。

## 三个模型如何公平比较

1. 读取BasicTS格式的流量、日内时段和星期；按时间先划分训练floor(0.6T)、验证floor(0.2T)、测试剩余部分，再在各划分内部构造12步输入和12步目标，不跨边界。
2. 同一数据集/扰动/比例/扰动种子只生成一份共享包，三个模型读取同一份输入、干净目标、时间特征和掩码。
3. 只根据扰动后的训练历史窗口计算均值和总体标准差（ddof=0）；三个模型共享这组标准化参数。
4. 各模型保留当前模型结构、训练损失、优化器和轮数配置。STDN03/08默认训练种子233，其余为1，每个组合一次；可用`--training-seed`显式覆盖。
5. 道路图不删除缺失节点的边。完整运行的STWave时间图和HyperD周期初始化从扰动后的训练历史重新估计；不使用干净未来目标、验证或测试流量。重叠历史窗口对应同一原始时间点时取均值，未覆盖点不参与估计。HyperD未观测时间槽用标准化0初始化。
6. 最终比较统一排除真实目标为0的位置，计算原始流量单位下的MAE、RMSE与MAPE百分数；输出整体及未来1～12步指标。模型原生指标单独保留。

上述统一数据和评价协议与各模型原始论文实验存在细节差异。进行鲁棒性分析时，应另外运行`python run.py clean`作为同协议对照，不能直接把过去的原论文复现指标拼接进表格。

## 保存的内容

每个共享包保存扰动输入、干净输入、干净目标、时间特征、源时间下标与选中位置掩码；`manifest.json`记录节点集合、各划分实际选中数量/比例、随机种子、标准化参数及数组SHA256。原本已为0但被选中的位置也计入扰动数量。

每个模型保存最佳权重及原生输出，另输出`robust_test_results.npz`（输入、干净输入、预测、真实值、掩码、时间特征和时间下标）和`robust_metrics.json`（整体与12步指标、模型/扰动种子、共享包指纹）。共享包摘要不符、模型实际输入或目标与共享包不一致时会拒绝出具结果。

## 小规模检查与正式实验

`--smoke`只取每个划分4个窗口，batch2、训练1轮，结果单独存入smoke目录。STWave在这种检查中使用临时环状时间图；它只验证执行链路，不能用来报告模型精度。完整运行会从实际训练历史估计时间图。

默认每种扰动36个组合：4数据集×3比例×3模型，每个组合一次；三种共108个组合。`--include-clean`额外增加每模型/数据集一次对照，默认不重复多随机种子实验。

输出已有完整结果时会跳过；存在部分权重但未完成时拒绝覆盖，需要新tag重新开始。本入口暂不支持鲁棒性训练中断续训，也不自动降低batch或切换设备。
